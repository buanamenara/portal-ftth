# portal-ftth

Sistem kerja proyek FTTH PT Buana Menara Indonesia: Portal FTTH, Portal Waspang + bot WhatsApp IRIS, Gateway, dan IRIS Gateway WhatsApp.

**Untuk AI atau developer yang melanjutkan:** baca [`AGENTS.md`](AGENTS.md) (cara kerja, aturan, cara deploy) dan [`MEMORY.md`](MEMORY.md) (keadaan terakhir, versi live, pekerjaan menunggu). Setiap perubahan ikut memperbarui `MEMORY.md`; deploy lewat GitHub Actions mencatatnya otomatis.
